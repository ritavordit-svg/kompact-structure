# 🚀 Kompact Project Setup Guide

## 1️⃣ Chuẩn bị môi trường

Trước khi bắt đầu, đảm bảo máy bạn đã cài đặt các công cụ sau:

| Công cụ | Phiên bản khuyến nghị |
|----------|------------------------|
| **Vue.js** | latest |
| **Node.js** | v20.11.1 |
| **npm** | v10.2.4 |
| **Git** | latest |
| **MongoDB** | latest |

---

## 2️⃣ Clone project

```bash
git clone https://github.com/<tên_repo>/staging-kompact.git
cd staging-kompact
```
## 3️⃣ Build Frontend Kompact
```bash
cd frontend
npm install
npm run build
```

## 4️⃣ Build Frontend Installation
```bash
cd installation
npm install
npm run build
```

## 5️⃣ Cấu hình file môi trường .env

## 6️⃣ Run Source Chính
```bash
npm run basic-install
```

## 7️⃣ Các bước Installation

Mở trình duyệt và truy cập: 

👉 http://localhost:4000/installation#/

(Tùy theo môi trường triển khai, có thể là domain thật nếu deploy trên server)

Làm theo các bước bên trên bạn sẽ được tạo 1 bộ company đầy đủ
